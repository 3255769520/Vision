# 题 8：黑色画布变灰 · `08_canvas.py`

## 1. 本实验要做什么

不读磁盘图片，用 NumPy **创建** 一张 **320×320** 的黑色正方形图，显示约 5 秒；再把**全部像素**改成 **100**（中性灰），再显示约 5 秒；最后**自动**关窗（靠两次 `waitKey(5000)` 超时，无需 Esc）。

## 2. 你会用到的库

| 库 / 模块 | 职责 |
|-----------|------|
| `numpy`（`np`） | `zeros` 创建数组、切片赋值 |
| `cv2` | `imshow`、`waitKey`、`destroyAllWindows` |

## 3. 核心 API / 方法精讲

### `np.zeros(shape, dtype=np.uint8)`

```python
canvas = np.zeros((320, 320, 3), dtype=np.uint8)
```

| 参数 | 含义 |
|------|------|
| `(320, 320, 3)` | 高 320、宽 320、3 通道（与彩色 OpenCV 图一致） |
| `dtype=np.uint8` | 每通道 0–255 像素常用类型 |

全 0 → BGR 都是 0 → **黑色**。

### 整图赋值

```python
canvas[:] = 100
```

- `[:]` 表示「所有元素」；赋值为标量 100 时，每个通道都变成 100。
- B=G=R=100 → **中性灰**（不是彩色）。

若写成 `canvas = 100` 会毁掉数组对象，只剩整数，后面 `imshow` 会失败——必须改**内容**而不是改**变量指向**。

### 显示节奏

同一窗口名 `"320x320 black / gray"`：先黑后灰；各 `waitKey(5000)`；最后 `destroyAllWindows()`。

## 4. Python 基础知识

### 形状元组

`(320, 320, 3)` 是一个元组，作为 `zeros` 的 shape。顺序仍是 **H, W, C**。

### 切片赋值 vs 重新绑定

```python
canvas[:] = 100   # 正确：改数组内容
# canvas = 100    # 错误：变量变成 int
```

### `dtype`

指定元素类型。图像处理里 `uint8` 几乎是默认选项；若用默认 `float64` 的 `zeros`，与 OpenCV 显示/保存约定可能不一致。
